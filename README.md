# ديوان

منصة ألعاب جماعية بالعربي: لبيب، خلية الحروف، بنت ولد، مين البرّاني؟، قدّر السعر، ودرب القوافل.

## 🎮 [العب هلأ](https://obadahaw.github.io/DIWAN/)

https://obadahaw.github.io/DIWAN/

## التشغيل على جهازك
لازم تنفتح من سيرفر محلي (مش بدبل كليك)، عشان الصور والأصوات والمجسّمات تنحمّل:

```bash
python3 -m http.server 8080
# أو: npx serve .
```

وبعدها افتح http://localhost:8080

## الملفات
- `index.html`: كل المنصة (CSS + HTML + JS).
- `*.webp`: شخصيات لبيب (`lb-*`) والنحلات (`qb-*`، `hb-*`، `kb-*`).
- `vo/`: جمل لبيب الصوتية (اختيارية، مطفية افتراضياً).
